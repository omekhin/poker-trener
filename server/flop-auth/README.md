# Как включить вход через Telegram на poker-trener.ru

Займёт около 20–30 минут, один раз. Пока ты этого не сделал, сайт работает как раньше: кнопки «Войти» нет, статистика хранится только в браузере.

**Как устроен вход.** Человек нажимает на сайте «Войти». Открывается твой бот в Telegram, человек жмёт «Запустить». Бот сообщает серверу: «это пользователь 12345, имя Илья». Сайт получает подтверждение и с этого момента хранит прогресс на сервере. Сервер — маленькая функция в Яндекс Облаке, данные лежат там же, в России.

Понадобятся:
- Telegram;
- аккаунт Яндекса;
- банковская карта — её надо привязать при регистрации в Яндекс Облаке. При твоих объёмах всё укладывается в бесплатные лимиты, но проверь тарифы на сайте облака.

---

## Шаг 1. Создай бота

1. В Telegram открой **@BotFather** и напиши `/newbot`.
2. Имя бота: например, `Флоп — вход`.
3. Username бота должен заканчиваться на `bot`, например `flop_poker_bot`. **Запиши его.**
4. BotFather пришлёт **токен**, похожий на `7123456789:AAH...`. Это пароль от бота: никому его не показывай. **Запиши.**

## Шаг 2. Придумай два секрета

Нужны две разные длинные случайные строки, по 30+ латинских букв и цифр. Сгенерируй их в любом генераторе паролей и запиши:
- `WEBHOOK_SECRET` — по нему сервер проверяет, что сообщение пришло именно от Telegram;
- `SESSION_SECRET` — им подписываются входы на сайте.

## Шаг 3. Зарегистрируйся в Яндекс Облаке

1. Зайди на **console.yandex.cloud** под своим Яндекс ID.
2. Создай платёжный аккаунт: привяжи карту, тип — физлицо.
3. Облако и каталог `default` создадутся сами. Дальше всё делаем в каталоге `default`.

## Шаг 4. Создай хранилище (бакет)

1. В меню слева: **Object Storage → Создать бакет**.
2. Имя: любое уникальное, например `flop-progress-ilya`. **Запиши.**
3. Доступ на чтение объектов, к списку объектов и к настройкам — **ограниченный** (закрытый). Остальное не трогай.
4. Нажми **Создать бакет**.

## Шаг 5. Создай сервисный аккаунт

Это «робот», от имени которого функция пишет в бакет.

1. В меню: **Identity and Access Management → Сервисные аккаунты → Создать**.
2. Имя: `flop-fn`.
3. Роль: **storage.editor**.
4. Нажми **Создать**.

## Шаг 6. Создай функцию

1. В меню: **Cloud Functions → Создать функцию**. Имя: `flop-auth`.
2. Открой функцию → вкладка **Обзор** → включи **Публичная функция**. Без этого сайт и Telegram не смогут к ней обратиться.
3. Вкладка **Редактор**:
   - **Среда выполнения:** Node.js 22 (подойдёт любая от 18).
   - **Способ:** редактор кода.
   - Создай файл `index.js` и вставь туда всё из `index.js` из этого архива.
   - Создай файл `package.json` и вставь содержимое `package.json`.
   - **Точка входа:** `index.handler`.
   - **Таймаут:** 10 секунд. **Память:** 128 МБ.
   - **Сервисный аккаунт:** `flop-fn`.
   - **Переменные окружения** (четыре штуки):

     | Ключ | Значение |
     |---|---|
     | `BUCKET` | имя бакета из шага 4 |
     | `BOT_NAME` | username бота без @, например `flop_poker_bot` |
     | `WEBHOOK_SECRET` | первый секрет из шага 2 |
     | `SESSION_SECRET` | второй секрет из шага 2 |

4. Нажми **Сохранить изменения** и дождись, пока создастся версия.
5. На вкладке **Обзор** скопируй **ссылку для вызова**. Она выглядит так: `https://functions.yandexcloud.net/d4e1abc2def3...`. **Запиши — это адрес сервера.**

**Проверка.** Открой в браузере `адрес_сервера?a=start`. Должно появиться что-то вроде `{"code":"...","link":"https://t.me/flop_poker_bot?start=..."}`. Если видишь `not_configured`, проверь переменные окружения.

## Шаг 7. Подключи бота к функции

Собери ссылку. Подставь свои значения вместо `ТОКЕН`, `d4e1abc...` и `СЕКРЕТ`:

```
https://api.telegram.org/botТОКЕН/setWebhook?url=https%3A%2F%2Ffunctions.yandexcloud.net%2Fd4e1abc...%3Fa%3Dtg&secret_token=СЕКРЕТ
```

- `ТОКЕН` — токен бота из шага 1. Слово `bot` перед ним оставь.
- `d4e1abc...` — хвост адреса функции после `functions.yandexcloud.net/`.
- `СЕКРЕТ` — `WEBHOOK_SECRET`.
- `%2F` и `%3F` не меняй: это закодированные `/` и `?`.

Открой ссылку в браузере. Должно прийти `{"ok":true,"result":true,"description":"Webhook was set"}`.
Если `api.telegram.org` не открывается, включи VPN только для этого шага.

## Шаг 8. Включи вход на сайте

1. Открой файл `auth.js` из архива сайта.
2. В начале файла найди строку `var API='';`.
3. Вставь адрес функции из шага 6, например:
   `var API='https://functions.yandexcloud.net/d4e1abc2def3...';`
4. Загрузи `auth.js` на GitHub, как обычно.

Через минуту-две на сайте в меню появится **«Войти»**.

## Шаг 9. Проверь

1. На сайте нажми **«Войти»** → **«Открыть Telegram»** → в боте нажми **«Запустить»**.
2. Бот ответит «Готово…», а в меню сайта вместо «Войти» появится твоё имя.
3. Зайди на сайт с другого устройства, войди тем же Telegram — статистика подтянется.

---

## Если что-то не работает

- **«Сервер входа не отвечает».** Функция не публичная, или в `auth.js` неправильный адрес.
- **Бот не отвечает на «Запустить».** Повтори шаг 7 и проверь, что `secret_token` совпадает с `WEBHOOK_SECRET` один в один.
- **Бот отвечает, а на сайте вход не проходит.** Проверь, что у функции выбран сервисный аккаунт `flop-fn` с ролью `storage.editor` и что `BUCKET` написан без ошибок. Ошибки видны на вкладке функции **Логи**.
- **Сайт на другом адресе.** Добавь переменную `ALLOWED_ORIGINS` со списком адресов через запятую, например `https://poker-trener.ru,https://www.poker-trener.ru`.

## Что с законом

После включения входа сайт хранит персональные данные: имя и Telegram ID. Политика конфиденциальности на сайте уже обновлена, данные лежат в России.

Формально оператор персональных данных должен подать уведомление в Роскомнадзор (152-ФЗ). Это бесплатно, онлайн на pd.rkn.gov.ru. Перед публичным запуском лучше это сделать или уточнить у юриста.

# Ежедневное напоминание в боте

Раз в день, в 19:00 по Москве, бот пишет тем, кто вошёл на сайт и ещё не выполнил цель дня:
- если серия идёт: «🔥 Серия 6 дней подряд — не прерви её! Сегодня осталось 12 очков…»;
- если серии нет: «Сегодня ещё без тренировки…».

Под сообщением две кнопки: «Открыть тренажёр» и «Пуш/фолд».

Кому бот **не** пишет:
- тем, кто уже выполнил цель дня;
- тем, кто не заходил больше недели;
- тем, кто написал боту `/stop`. Включить обратно — `/remind`.

## Шаг 1. Обнови функцию

1. Cloud Functions → `flop-auth` → **Редактор**.
2. Замени весь `index.js` на новый из архива.
3. Добавь переменную окружения `BOT_TOKEN` — токен бота от BotFather.
4. **Таймаут** поставь 60 секунд: если пользователей много, рассылка идёт дольше.
5. Нажми **Сохранить изменения**.

## Шаг 2. Дай сервисному аккаунту право запускать функцию

1. Открой каталог `default` → вкладка **Права доступа** → **Настроить доступ**.
2. Выбери `flop-fn`.
3. Добавь роль **functions.functionInvoker** и сохрани.

## Шаг 3. Создай триггер-таймер

1. Cloud Functions → **Триггеры** → **Создать триггер**.
2. **Имя:** `flop-remind`. **Тип:** Таймер.
3. **Cron-выражение:** `0 16 ? * * *` — это 16:00 по UTC, то есть 19:00 по Москве. Хочешь 20:00 — поставь `0 17 ? * * *`.
4. **Функция:** `flop-auth`, тег `$latest`.
5. **Сервисный аккаунт:** `flop-fn`.
6. Нажми **Создать триггер**.

## Шаг 4. Проверь сразу, не дожидаясь вечера

Открой в браузере `адрес_функции?a=remind&key=WEBHOOK_SECRET` (подставь свой адрес и секрет).

Придёт что-то вроде `{"users":3,"sent":1,"skipped":2}`. Если ты сегодня не выполнил цель, напоминание придёт и тебе.

**Внимание:** эта ссылка правда рассылает напоминания всем подходящим пользователям, не жми её много раз подряд.

Если `sent` равен 0, а ты точно подходишь, открой вкладку функции **Логи**. Строчки `send ...` с ошибкой означают, что облаку не удалось достучаться до Telegram — скинь мне скрин.

## Шаг 5. Команды в меню бота (по желанию)

В @BotFather: `/setcommands` → выбери бота → отправь:

```
stop - выключить напоминания
remind - включить напоминания
```
